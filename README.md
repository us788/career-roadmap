# career-roadmap

컴퓨터공학 취업 준비 로드맵과 매일 체크용 트래커입니다.

- **매일 트래커**: https://us788.github.io/career-roadmap/
- **로드맵 문서**: [docs/roadmap.pdf](docs/roadmap.pdf)
- **마일스톤 체크리스트**: [MILESTONES.md](MILESTONES.md)

## 주간 루틴

하루 로드맵 시간은 4시간입니다. 딥워크 2시간 30분에 고정 루틴 1시간 30분(코딩 테스트 45분, CS 30분, OPIc 15분)을 더합니다.

| 요일 | 딥워크 주제 | 운동 |
|---|---|---|
| 월 | Java / Spring | |
| 화 | AI 엔지니어링 | ✓ |
| 수 | Java / Spring | |
| 목 | AI 엔지니어링 | ✓ |
| 금 | 백엔드 실무 (기초 단계에는 Java / Spring) | ✓ |
| 토 | 백엔드 통합 실습과 주간 커밋 | ✓ |
| 일 | 휴식, 주간 회고 30분 | |

## 운영 규칙

- 시험 2주 전부터는 트래커의 시험 기간 모드를 켜고 고정 루틴 1시간만 합니다.
- 일요일 회고 때 `MILESTONES.md`를 갱신하고, 밀린 항목은 다음 주 토요일로 넘깁니다.
- 하루를 놓쳐도 다음 날 몰아서 만회하지 않습니다.

## 트래커 사용법

- 할 일을 누르면 체크되고, 상단 막대에 오늘 채운 시간이 표시됩니다.
- 주간 칸을 누르면 지난 날짜의 기록을 보거나 고칠 수 있습니다.
- 설정에서 시험 기간 모드와 학습 단계(기초 / 실무)를 바꿀 수 있습니다. 바꾼 설정은 오늘과 이후 날짜에만 적용됩니다.
- 기록은 각 기기의 브라우저에 저장됩니다. 기기를 옮길 때는 설정의 내보내기 / 불러오기를 씁니다.
- 폰에서는 브라우저의 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.
